# Tessera: панель — план работ

> **Для исполнителя:** ОБЯЗАТЕЛЬНЫЙ ПОДСКИЛЛ — `superpowers:executing-plans`.
> Шаги помечены чекбоксами.

**Цель:** панель, которая рисует блоки, приходящие с сервера, и не знает, кто
их наполняет — ядро или чужой модуль.

**Устройство:** статика без сборки, вшитая в бинарник через `embed`. Разметка,
стили и способ рисования берутся из принятого макета: растр, монохром, тёмная
тема, вкладка в адресе строки. Вместо вшитых данных панель ходит в
`/api/tabs`, `/api/layout` и `/api/block`.

**Стек:** ванильный JS, ноль зависимостей, шрифты подшиты в файл.

**Спека:** `docs/superpowers/specs/2026-08-14-tessera-core-design.md`
**Макет:** https://claude.ai/code/artifact/89b534c7-0826-419b-bb9d-d343ee252e50
(исходники — `~/Projects/tessera-mockup`)

## Общие требования

- Панель не считает данные: она рисует то, что пришло. Никакой арифметики
  сверх процентов и долей для отрисовки.
- Ни одного обращения к сети за пределы своего сервера: шрифты подшиты,
  библиотек нет.
- Блок с неотвечающим источником рисуется честной надписью, а не пустотой и не
  падением всей страницы.
- Тексты по-русски, включая ошибки.
- Тёмная тема и ширина телефона проверяются браузером, а не на глаз.

Взять `~/Projects/tessera-mockup/tessera.html`, оставить стили, шрифты,

- [ ] **Шаг 2: Отдача статики из бинарника**

`internal/api/web.go`:

```go
package api

import (
	"embed"
	"io/fs"
	"net/http"
)

//go:embed all:web
var веб embed.FS

// Static отдаёт панель. Файлы вшиты в бинарник: рядом с ним не должно лежать
// ничего, кроме базы и модулей.
func Static() http.Handler {
	под, err := fs.Sub(веб, "web")
	if err != nil {
		panic(err) // такое ловится сборкой, а не в работе
	}
	return http.FileServer(http.FS(под))
}
```

Папка `web` при этом должна лежать рядом с `web.go`, поэтому переносится в
`internal/api/web/`.

- [ ] **Шаг 3: Форма входа**

Панель при загрузке спрашивает `/api/state`. `signedIn:false` — показывает
форму с одним полем; `passwordSet:false` — подсказывает, что пароль задаётся
флагом `--password` при первом запуске.

- [ ] **Шаг 4: Проверить в браузере**

`node shots.mjs` (перенести из макета): страница открывается, форма видна,
после входа появляется каркас.

### Задача 3: Заготовки stat, columns, raster, table

**Файлы:** `internal/api/web/blocks.js`

- [ ] **Шаг 1: stat**

Крупное число, подпись, разбивка `parts` мелкой строкой, прирост `delta`
таблеткой. Разбивка — то, чем плитка «Всего людей» делится на iOS и Android.

- [ ] **Шаг 2: columns**

Столбики из макета: весь слот минус два пикселя зазора, штриховка у второй
части, тултип по наведению.

- [ ] **Шаг 3: raster**

Ряды кусочков: один кусочек равен `unit`, подпись из `unitLabel`, ряды
сортируются по убыванию, последний кусочек неполного ряда серый.

- [ ] **Шаг 4: table**

Таблица с полосой по колонке `barCol`, имена через словарь.

### Задача 5: Словарь имён и период

**Файлы:** `internal/api/web/panel.js`

- [ ] **Шаг 1: Имена с сервера**

`GET /api/labels?app=…` при загрузке; `nameOf` берёт оттуда. Правка по кнопке в
строке шлёт `POST /api/labels` и обновляет экран.

- [ ] **Шаг 2: Тумблер ключей**

«Ключи из кода» возвращает сырые имена, как в макете.

- [ ] **Шаг 3: Период**

Кнопки «7 дней · 15 · 30 · всё» меняют `range` у всех блоков вкладки. Плитки с
собственным окном (онлайн, активные) на период не реагируют — это их свойство,
а не недосмотр.
