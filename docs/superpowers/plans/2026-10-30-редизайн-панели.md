# Редизайн панели по макету v2 — план работ

> Исполнение: сам, в этой сессии, без агентов (правило владельца). Шаги с галочками.

**Цель:** панель на проде выглядит и ведёт себя как принятый макет
https://claude.ai/artifact/HXq53Q1HEbWYthBSy9ZHxA (исходник —
`tessera-mockup/redesign/`, рабочая копия макета в скретчпаде сессии).

**Архитектура:** оболочка (боковое меню вместо верхней шапки), токены, шрифты
и движение переносятся из макета целиком. Вкладки ядра (Обзор, Экраны, Люди)
переносятся кодом макета на живые `DATA`. Вкладки модулей остаются блоками:
у общего набора появляются новые заготовки (`periods`, `waffle`, `rows`,
`rate`), а старые (`stat`, `raster`, `list`, `note`, `columns`, `table`,
`search`, `shelf`) получают вид макета. Логика ленты (запас, срез `top`,
память места, выбор пальцем) не трогается: меняется только оформление,
классы DOM остаются, тесты ленты продолжают работать.

**Стек:** Go (ядро), ванильный JS без сборки, Python-модули.

## Общие ограничения

- Шрифты свои, вшитые: Golos Text 400/500/600, JetBrains Mono 400/500
  (woff2, кириллица и латиница). Внешних запросов панель не делает.
- Цвета только токенами, тема авто/светлая/тёмная как в макете.
- `prefers-reduced-motion` гасит всё движение.
- Данные макета в репозиторий не попадают (живые числа дохода).
- Панель не считает агрегаты на запросе: новые поля `/api/core` читают сводки.

## Что чем становится

| Было | Стало |
|---|---|
| Верхняя шапка, строка контекста, ряд вкладок | Боковое меню: приложение, «Меню», «Модули», тема, «Свой сервер · собрано N мин назад · обновить · выйти» |
| Глобальный период | Период там, где он что-то меняет: фильтр «Экранов», шапки «Воронок» и «Версий». Обзор и Люди берут всю историю, срез 15 суток для экранов и действий |
| Тумблер «Ключи из кода» | Ключ всегда виден мелкой строкой под именем, имя правится карандашом |
| «Настроить вкладку» | Остаётся на вкладках модулей тихой строкой внизу |

## Задачи

- [ ] **1. Ядро отдаёт историю и часы.** `/api/core`: `history` — все сутки
  (`d, nw, ret, partial`), `hourly` — `{start, rows[день][24]}` людей в час
  по UTC из сводки `hourly`. Тест `TestЯдроОтдаётИсториюИЧасы`.
- [ ] **2. Шрифты, токены, оболочка.** `web/fonts/*.woff2`, `panel.css` с нуля
  по макету плюс совместимость для старых классов Воронок, Версий,
  Приложений и модулей `appdb`, `club`; `index.html` с боковым меню.
- [ ] **3. Движение.** `web/motion.js`: кривая, `anim`, перетекание чисел,
  прорисовка графиков, подложка переключателей, вход карточек, каркас
  первой загрузки, мягкая перерисовка, смена вкладки.
- [ ] **4. Каркас панели.** `panel.js`: меню из `/api/tabs`, выбор приложения,
  тема, свежесть и «Обновить», выход, отрисовка с движением, блоки с полем
  `with` (несколько источников в одном блоке).
- [ ] **5. Вкладки ядра.** `core-views.js`: Обзор, Экраны, Люди кодом макета;
  Воронки, Версии, Приложения в карточках.
- [ ] **6. Заготовки модулей.** `blocks.js`: рамка карточки, новые `periods`,
  `waffle`, `rows`, `rate`, переделанные `stat`, `raster`, `list`, `note`,
  `columns`, `table`, `search`; лента и лайтбокс в оформлении макета.
- [ ] **7. Модули.** `income/module.json` — раскладка макета, `main.py` отдаёт
  `shows` у рекламных блоков; `moderation/module.json` — поиск, растр с
  итогом, лента.
- [ ] **8. Проверка и выкатка.** `go test ./...`, тесты модулей, статическая
  сборка, замена бинарника и модулей, сброс сохранённой раскладки
  модерации, обновление модулей, тесты панели и снимки всех вкладок на проде
  (компьютер и телефон), коммит и пуш, правка `CLAUDE.md`.

## На что смотреть при проверке

- Wallet: одна платформа, нет модулей Togetherly — вкладки не падают.
- Установка без счёта людей: Обзор и Люди без `who` (нули, а не ошибки).
- Пустая `hourly` в первый день установки — сетка суток рисует пустые клетки.
- Лента: выбор пальцем, догрузка, место после перезагрузки — прежние тесты.
- Телефон 390 px: нет горизонтальной прокрутки.
