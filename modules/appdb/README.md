# База приложения

Модуль показывает то, чего аналитика знать не может: сколько людей
зарегистрировано, сколько из них дошло до второго шага, что накопилось в базе.
События отвечают на вопрос «кто заходил», а этот модуль — на вопрос «что там
лежит».

Разница видна на простом примере. Человек завёл аккаунт в июне и с тех пор не
открывал приложение: в событиях его нет, а в таблице `users` он есть. Поэтому
плитка «Всего людей» приходит отсюда, а «Активны за месяц» — из ядра.

## Как поставить

Положите папку рядом с бинарником Tessera:

```
tessera
modules/appdb/module.json
modules/appdb/main.py
```

Дальше в `module.json` правится одно поле и запросы под своё приложение:

```json
"sql": {
  "db": "/opt/pocketbase/pb_data/data.db",
  "blocks": { ... }
}
```

Секцию `sql` читает только сам модуль: для ядра это лишнее поле манифеста,
которое оно молча пропускает.

## Как проверить, не открывая панель

Модуль — обычная программа, поэтому запускается руками:

```
cd modules/appdb
python3 main.py collect            # всё разом, как это делает расписание
python3 main.py query users_total  # один блок
```

Что напечатано в вывод, то и увидит панель.

## Виды блоков

| Тип | Что описывать | Что вернёт запрос |
|---|---|---|
| `stat` | `query`, необязательно `parts` и `delta` | одно число; разбивка — пары «имя, число» |
| `list` | `query` | пары «имя, число» |
| `table` | `cols`, `query`, `barCol` | строки таблицы |
| `raster` | `query`, `unit`, `unitLabel` | пары «имя, число» |
| `columns` | `query`, `unit` | пары «подпись, число» по дням |
| `funnel` | `steps` со своим `query` у каждого | по одному числу на шаг |
| `heat` | `cols`, `query` | подпись ряда и числа по колонкам |

## Три правила, встроенные в модуль

**База открывается только на чтение.** `mode=ro` плюс `PRAGMA query_only`:
аналитика не имеет права писать в чужие данные даже по ошибке.

**У каждого запроса есть предел по времени.** Восемь секунд, дальше запрос
прерывается. Это защита живого приложения: один тяжёлый JOIN по большой базе
кладёт не только панель, но и само приложение.

**Упавший запрос не уносит остальные.** Блок останется без данных, панель
покажет это честной надписью, прочие блоки посчитаются.

## Заготовка под Togetherly

Лежащий в `module.json` набор написан под базу приложения для пар: пары, соло,
воронка до первого воспоминания, монеты, удержание по неделям. Для другого
приложения меняются запросы, а типы блоков и сам модуль остаются.
