# Доход

Деньги из рекламных кабинетов и магазинов одной вкладкой: сколько пришло
сегодня, за месяц и за год, кто из источников сколько дал, как это менялось по
месяцам.

## Модуль не ходит в чужие API

Он читает готовые сводки, которые кладёт отдельный сбор по расписанию. Так
сделано намеренно: поход в четыре кабинета — дело долгое, с ключами, лимитами и
отказами. Сложить его в путь запроса от панели значит получить экран, который
грузится минуту и падает, когда у Google плохой день.

Сбор отвечает за «сходить и записать», модуль — за «показать записанное».
Поэтому весь сбор занимает сорок миллисекунд.

## Настройка

В `module.json` указываются два файла:

```json
"files": {
  "summary": "/opt/pocketbase/pb_data/.income.json",
  "history": "/opt/pocketbase/pb_data/.income_history.json"
}
```

Первый — текущая сводка (сегодня, вчера, месяц, источники), второй — история по
месяцам и годам. Формат ожидается такой:

```json
{ "totals": { "today": 45.86, "yesterday": 33.34, "month": 354.59 },
  "sources": { "rsya": { "ok": true, "title": "Яндекс, реклама",
                         "today": 18.24, "month": 40.08, "prev_month": 18.46,
                         "note": "баланса и порога выплаты в их API нет вовсе" } },
  "rates": { "rub_per_usd": 83.27 },
  "sold": { "plus_total": 40, "plus": { "lava": 26, "play": 11, "code": 3 } } }
```

Источник без ключа сводку не ломает: `ok: false` рисуется строкой «не
подключён», иначе непонятно, почему в общей сумме нет одного из кабинетов.

## Что показывается

Плитки за месяц, сегодня и вчера с разбивкой по источникам; таблица источников
со сравнением с прошлым месяцем; столбики по месяцам; продажи полного доступа с
разбивкой по каналам; география и системы, где показывается реклама; сумма за
год с поправкой на текущий месяц.

Последнее стоит пояснить: история собирается ночью, а сводка обновляется каждые
двадцать минут. Без поправки год оказывался меньше собственного последнего
месяца.

## Оговорки на видном месте

Отдельным блоком выводятся примечания источников: что отчёт Google Play выходит
в начале следующего месяца, что рубли приведены к доллару по курсу дня сборки, а
не по курсу на дату платежа. Это те вещи, из-за которых числа расходятся с
кабинетом на несколько процентов, и держать их в голове не нужно.
