# Tessera

Аналитика мобильных приложений, которая живёт на вашем сервере.

Один файл, база рядом с ним, панель внутри. Скачали, запустили, задали пароль,
поставили SDK — через минуту видно, что происходит в приложении. Ни облаков, ни
чужих условий, ни контейнеров: у соседей по нише на этом месте три штуки.

**Людей по умолчанию не считаем.** Событие уходит без идентификатора вовсе,
поэтому панель работает без согласий и баннеров. Тумблер «считать людей»
включается осознанно, и только тогда появляются удержание, когорты и воронки.

## Как устроено

Панель собирается из блоков: плитка с числом, столбики по дням, ряды кусочков,
таблица, карта двух величин, воронка, матрица когорт. Ядро рисует себя тем же
механизмом, что достаётся сторонним модулям, поэтому чужой блок встаёт в
дашборд наравне со своим.

Модуль — папка с манифестом и программой на любом языке. Ядро запускает её по
расписанию и читает то, что она напечатала. Так к аналитике добавляются вещи,
про которые она знать не обязана: доход из рекламных кабинетов, лента файлов на
модерацию, падения, нагрузка сервера.

## Состояние

В работе. Спека ядра: [docs/superpowers/specs](docs/superpowers/specs).
Внешний вид панели принят макетом, оформление растровое.

## Имя

Tessera — кусочек смальты, из которых складывается мозаика. Панель собирается
из таких же кусочков, и каждое число в ней читается счётом, а не сравнением
длин на глаз.
